# Proxima Community Manager IA

## Présentation

Ce projet vise à utiliser l'intelligence artificielle
pour soutenir la gestion de la communication numérique
de Proxima.

## Objectifs

- Élaborer une stratégie éditoriale.
- Préparer des publications pour les réseaux sociaux.
- Concevoir un calendrier éditorial.
- Adapter les contenus aux différents publics.
- Analyser les performances des publications.
- Renforcer la visibilité et la crédibilité de Proxima.

## Réseaux sociaux concernés

- LinkedIn
- Facebook
- Instagram
- X

## Missions de l'assistant IA

L'assistant doit proposer des contenus cohérents avec
le positionnement de Proxima dans les domaines de
l'éducation, de l'environnement et du développement durable.
